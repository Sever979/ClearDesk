# ClearDesk 1.1.0 — первая публикация

Локальная программа очистки и мониторинга Windows от **Sever979**.

## Скачать

- `ClearDesk-Setup.exe` — установка с ярлыками и записью удаления в Windows.
- `ClearDesk-1.1.0-portable.zip` — запуск без установки, инструкция и лицензия.
- `SHA256SUMS.txt` — контрольные суммы файлов выпуска.

## Доступно

Мониторинг CPU, RAM, дисков, сети и процессов; ручная очистка пользовательского Temp; поиск вероятных остатков приложений в разделах Uninstall реестра с резервными копиями; работа в трее.

## Изменения 1.1

Сведения об авторе и контактах, вкладка «О программе», метаданные EXE, встроенная лицензия, принятие условий при установке и описание будущей Pro-редакции.

## Ограничения

Файлы удаляются без корзины после выбора и подтверждения. Кандидаты реестра требуют ручной проверки. Для изменения HKLM нужны права администратора. Программа не гарантирует ускорения Windows. Дистрибутив не подписан цифровым сертификатом.

Pro пока не реализован и не продаётся; текущие функции бесплатны. Условия использования — в LICENSE.txt. Исходный код опубликован не под открытой лицензией.

## Проверка

Локально прошли сборка, проверки границ и возраста файлов, защиты изменённых файлов, отрисовка вкладок, экспорт/удаление/восстановление синтетической записи HKCU. Проверка всех версий Windows не проводилась.
